# My Movies

Личная фильмотека для macOS. Хранит фильмы, оценки, статусы, жанры и обложки
локально на вашем Mac — без регистрации и облачного сервиса.

[Скачать My Movies 0.3.0 (.dmg)](https://github.com/vehxi/MyMovies/releases/download/v0.3.0/MyMovies-0.3.0.dmg)

Требуется macOS 26 Tahoe или новее. Приложение работает на Mac с Apple Silicon
и Intel.

## Установка

1. Скачайте и откройте `MyMovies-0.2.0.dmg`.
2. Перетащите **My Movies** в папку **Applications**.
3. Запустите приложение из **Applications**.

Текущая версия ещё не нотариализована Apple, поэтому при первом запуске macOS
может заблокировать приложение. После попытки запуска откройте
**Системные настройки → Конфиденциальность и безопасность**, прокрутите до
раздела **Безопасность** и нажмите **Всё равно открыть**.

## Возможности

- библиотека фильмов с постерами и несколькими жанрами;
- статусы «Хочу посмотреть», «Смотрю», «Просмотрено» и «Брошено»;
- независимая категория «Любимое», совместимая с любым статусом;
- оценки и предупреждение о возможных дубликатах;
- отдельный tier list;
- добавление обложек через Finder, drag-and-drop и буфер обмена;
- русский и английский языки;
- светлая и тёмная системные темы.

## Данные и приватность

Все данные и обложки хранятся только локально в контейнере приложения. My
Movies не требует аккаунта и не отправляет вашу фильмотеку на сервер.

## Удаление всех данных

1. Закройте My Movies.
2. В Finder нажмите `⇧⌘G` и откройте `~/Library/Containers/`.
3. Переместите `com.vehxi.MyMovies` в Корзину.

При следующем запуске приложение создаст новую пустую библиотеку.
