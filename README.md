# Kadr

## Ваша коллекция. На вашем Mac.

Kadr помогает собрать фильмы и сериалы в одном месте, следить за
просмотром и сохранять то, к чему хочется вернуться. Без аккаунта, подписки и
облачной синхронизации.

[Скачать последнюю версию](https://github.com/vehxi/Kadr/releases/latest)

Для macOS Tahoe 26 и новее. Поддерживаются Mac с Apple Silicon и Intel.

## Всё, что вы смотрите

- фильмы и сериалы в единой медиатеке;
- сезоны, эпизоды и прогресс просмотра;
- статусы «Хочу посмотреть», «Смотрю», «Просмотрено» и «Брошено»;
- избранное, оценки, жанры и заметки;
- собственный тир-лист для фильмов;
- обложки из Finder, буфера обмена или перетаскиванием.

Интерфейс доступен на русском и английском языках, поддерживает светлое и
тёмное оформление macOS.

## Приватность — по умолчанию

Медиатека и обложки хранятся только на вашем Mac. Приложение не требует
регистрации и не передаёт данные внешним сервисам.

## Установка

1. Скачайте и откройте DMG-файл последней версии.
2. Перетащите **Kadr** в папку **Программы**.
3. Откройте приложение из папки **Программы**.

Сборка распространяется напрямую и пока не нотариализована Apple. Если macOS
заблокирует первый запуск, откройте **Системные настройки → Конфиденциальность
и безопасность**, найдите сообщение о Kadr и нажмите **Всё равно открыть**.

## Удаление данных

1. Закройте Kadr.
2. В Finder нажмите `⇧⌘G` и перейдите в `~/Library/Containers/`.
3. Переместите `com.vehxi.MyMovies` в Корзину.

При следующем запуске будет создана новая пустая медиатека.

## Выпуск обновления

Приватный ключ Sparkle хранится только в Keychain разработчика и не
загружается в GitHub. Чтобы выпустить новую версию:

1. Измените **Version** приложения в Xcode на следующий номер в формате
   `major.minor.patch`, например `0.4.1`.
2. Закоммитьте и отправьте все изменения в ветку `main`.
3. В корне проекта выполните `./scripts/publish-release.sh`.
4. При запросе macOS разрешите утилите Sparkle доступ к ключу
   `com.vehxi.Kadr` в Keychain.

Скрипт проверит состояние репозитория, соберёт универсальный DMG для Apple
Silicon и Intel, подпишет обновление локальным ключом и создаст GitHub Release.
Сам приватный ключ Mac не покидает.
